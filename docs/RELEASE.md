## English

CueFlow 1.0.0 synchronizes an existing SRT with a video using local speech detection
and ffsubsync. Includes English/Spanish controls, drag and drop, cancellation, encoding
repair, timing-speed correction and output naming that preserves existing files.

Choose the archive for your operating system and processor. Extract the whole archive
before opening the app. FFmpeg, ffprobe and Python are included. These initial builds
are unsigned; macOS builds are not notarized. See the README for opening instructions.

Each downloadable build must pass source tests and a frozen-app smoke test before
this release is published. Check the adjacent `.sha256` file to verify a download.
The FFmpeg source archive is provided for license compliance; it is not the desktop app.

## Español

CueFlow 1.0.0 sincroniza un SRT existente con un video mediante detección local de voces
y ffsubsync. Incluye interfaz en español e inglés, arrastrar y soltar, cancelación,
reparación de codificación, corrección de velocidad y guardado que conserva los archivos.

Elige el paquete de tu sistema y procesador. Extrae todo el contenido antes de abrir la
aplicación. Incluye FFmpeg, ffprobe y Python. Estas primeras compilaciones no tienen firma
de editor y las de macOS no están notarizadas. Consulta las instrucciones en el README.

Cada descarga debe superar las pruebas de código y del ejecutable antes de publicarse.
El archivo `.sha256` permite verificarla. El archivo fuente de FFmpeg se incluye por su
licencia; no es la aplicación de escritorio.
